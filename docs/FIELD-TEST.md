## ข. บั๊กที่การทดสอบนี้เจอ (แก้แล้วทั้งหมด)

1. **เดินออกนอกสัญญาณแล้วกลับมา ข้อมูลไม่ส่งอีกเลย** — การต่อใหม่ค้างตลอดไปถ้าคำขอแรกถูกกลืนหาย (4G อ่อน, WiFi ที่ต้องล็อกอิน) → ให้ถือว่าเงียบนานเกิน = หลุด แล้วต่อใหม่
2. **Render หลับกลางการแข่ง** ทั้งที่ยังมีเครื่องต่ออยู่ (มันนับแค่ HTTP) → แอปเรียก `/health` ทันทีที่เปิดห้องและทุก 4 นาที
3. **กดรัวๆ แล้วส่งข้อมูลซ้ำแบบทวีคูณ** (40 รอบ = ~65,000 ข้อความ) → ส่งแต่ละบันทึกครั้งเดียวต่อการเชื่อมต่อ
4. **แถบ "แตะผิด" ทับปุ่มหยุดของเลนล่างสุด** 6 วินาทีหลังทุกการกด → ย้ายไปช่องคงที่ด้านบน
5. **8 เลนล้นจอมือถือ** ต้องเลื่อนระหว่างกด → แถวกระชับลงเมื่อเกิน 6 คน (ตรวจด้วย Edge: ทุกปุ่มหยุดอยู่ในจอและกดถึง)
6. มือถือเพิ่งปลดล็อกจอค้างสถานะ "ออนไลน์" ปลอมได้ 12 วิ → ต่อใหม่ทันทีเมื่อเปิดจอ
7. มือถือรุ่นเก่าอาจเปิดไม่ขึ้น → build แบบ ES2019 (Safari 12.1+ / Chrome 73+)
8. มือถือช้ากำลังวาดจอตอนนิ้วแตะ = เวลาเพี้ยน 10–30ms → ใช้เวลาจริงจากเหตุการณ์สัมผัส

## ค. ต้องทดสอบที่สนามจริง (ซ้อมก่อนวันแข่ง ~30 นาที)

สิ่งที่คอมจำลองไม่ได้ — ทำในวันซ้อมที่สนามจริง เวลาเดียวกับวันแข่ง (15:00–17:00):

- [ ] **M01** เปิดแอปบนมือถือทุกเครื่องที่จะใช้จริง รวมเครื่องเก่าสุด — ขึ้นหน้าแรก ไม่จอขาว
- [ ] **M02** เปิดลิงก์จาก LINE → ใช้ได้ไหม แล้วลอง ⋯ → "เปิดในเบราว์เซอร์"
- [ ] **M03** ยืนที่จุดเริ่มและเส้นชัยจริง ดูไฟสถานะ: เขียว "ออนไลน์" และ "±ms" ไม่เกิน ~±80ms
- [ ] **M04** อ่านจอกลางแดดบ่าย (โหมดสว่าง ☀ + ความสว่างสุด) หันหลังให้ดวงอาทิตย์
- [ ] **M05** วางมือถือรอ 5 นาที จอไม่ดับเอง (ถ้าดับ ตั้งเวลาปิดหน้าจอเป็น 10 นาทีในตั้งค่ามือถือ)
- [ ] **M06** จับเวลา 1 รอบคู่กับนาฬิกาจับเวลามือ — ต่างกันไม่เกิน ~0.2 วิ (เท่าความเร็วตอบสนองของคน)
- [ ] **M07** เครื่องเส้นชัยเปิดโหมดเครื่องบิน → กดหยุด 2 คน → ปิดโหมดเครื่องบิน → ผลขึ้นที่เครื่องอื่นภายใน ~15 วิ
- [ ] **M08** ล็อกจอเครื่องเส้นชัยระหว่างวิ่ง → ปลดล็อก → ยังกดหยุดได้ เวลาถูก
- [ ] **M09** กดผิดคน → "แตะผิด" → กดคนที่ถูก
- [ ] **M10** ออกตัวผิด → "ยกเลิกรอบนี้" → ปล่อยใหม่
- [ ] **M11** ไม่แตะแอปเลย 20 นาที → เปิดใหม่ → ขึ้น "ออนไลน์" ภายใน ~60 วิ
- [ ] **M12** จอเปียก/มือเปียก: เช็ดจอ แล้วลองกด (ถ้ามีกดเพี้ยน ใช้ "แตะผิด" หรือหน้าผล ⋮)
- [ ] **M13** แบต: ใช้ต่อเนื่อง 2 ชม. ลดไปเท่าไร (คาด 30–50%) เตรียมพาวเวอร์แบงก์
- [ ] **M14** ดาวน์โหลด CSV แล้วเปิดใน Excel ภาษาไทยถูก

- [ ] **M16** ให้ครูที่ไม่เคยใช้ ใช้โดยดูแค่โปสเตอร์

## ง. สิ่งที่ระบบช่วยไม่ได้

- **คนกดช้ากว่าระบบ**: ความเร็วตอบสนองของคน ~0.15–0.25 วิ ส่วนระบบคลาดแค่ ±20–80ms → ให้คนปล่อยตัวเป็นคนเป่านกหวีดเองถ้าทำได้
- **ห้าม push โค้ดระหว่างแข่ง**: Render deploy ใหม่อัตโนมัติ เซิร์ฟเวอร์รีสตาร์ท (ข้อมูลไม่หาย แต่สะดุด 10–30 วิ)
- **เปิดแอปก่อนรายการแรก 2 นาที** ถ้าไม่มีใครเปิดแอปเลยเกิน 15 นาที เซิร์ฟเวอร์จะหลับ
